版式实验

同一篇文章，三种结构

用《工作了18年，我依然没有自己的商业事业》的真实全文渲染。三者都沿用深色底与主色 #D8F26B，区别在断点、强调和段落节奏的组织方式。点任一长图可看原尺寸。

预览地址：/preview/reading-a.html · /preview/reading-b.html · /preview/reading-c.html

A 色带式

打开演示 →
  • 断点：整行低透明度主色带 + 左侧 4px 主色竖条 + 01/02 编号，节间留 64px
  • 强调：整块主色反色（深色字），每节最多 1–2 处
  • 引用：圆角卡片，主色细边 + 引号，不再是一根竖线
  • 段落：长段按语义拆到移动端 ≤4 行，段距 24px
  • 图片：图 + 图注成套，上下留白 46px

B 卡片式

打开演示 →
  • 断点：每节一张深灰卡片，顶部主色胶囊标签（01 · 恐惧）
  • 强调：卡内主色渐变块，与卡片底色强对比
  • 引用：独立深色卡，主色边框 + 右上引号
  • 段落：卡片内 20px 段距，卡片间距 20px，天然断行
  • 图片：卡内图 + 图注，不再跨卡片

C 杂志式

打开演示 →
  • 断点：左侧大号编号栏（吸顶）+ 顶部细分割线
  • 强调：主色文字 + 上下细线，无底色，像杂志拉版
  • 引用：低透明度主色方块卡，直角
  • 段落：19px / 1.95，段距 28px，留白最大
  • 图片：跨栏满宽，图注左对齐
